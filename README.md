# Numra for WooCommerce

Protect your WooCommerce store from Cash-on-Delivery (COD) fraud. Connect to your Numra account to score orders, verify phone numbers, and reduce failed deliveries.

## Features
* **Automated handshakes:** One-click OAuth connection flow with `app.numra.ma`.
* **State-aware connection lifecycle:** Displays real-time updates for `Connected`, `Connection Lost` (invalid/revoked keys), and `Temporarily Unavailable` states.
* **Auto Update Notifications:** Native integration with WordPress core update APIs. Get notified in your WordPress plugins list whenever a new version is released.
* **Growth Center alerts:** Access direct promotional and account-critical bulletins from Numra within your dashboard.

## Installation
1. Download the latest `numra-for-woocommerce.zip` archive.
2. Go to your WordPress Admin -> **Plugins** -> **Add New** -> **Upload Plugin**.
3. Choose the ZIP file, install, and click **Activate**.
4. Navigate to the **Numra** menu in your WordPress sidebar.
5. Click **Connect to Numra** to link your store.

## Minimum Requirements
* WordPress 5.8+
* WooCommerce 5.0+
* PHP 7.4+
